# 꿀시간표: 공강·강의평 분석 시간표 추천 + LLM 수강신청 전략

> 이 문서는 11/11 제출한 기획서 원본이다. 이후 확정된 설계(파일 구조, 데이터 수집 방식, 알고리즘)는 01–05 문서가 우선한다.

- 팀 이름: 꿀 시간표
- 팀원: 김지후, 이유찬
- GitHub 저장소: https://github.com/lynnpield-lang/Timetable-maker

## 목적과 해결할 문제
- 학생들은 매 학기 수강신청 전에 전자시간표, 강의평, 시간표 앱을 오가며 분반 조합을 손으로 맞춰본다.
- 공강 개수, 우주공강(수업 없는 요일), 1교시 수업 같은 조건은 조합이 많아질수록 직접 비교하기 어렵고, 인기 과목을 놓쳤을 때의 대안도 미리 준비하지 못한다.
- 꿀시간표는 듣고 싶은 과목과 선호 조건을 입력하면 시간이 겹치지 않는 시간표를 모두 만들어 점수순으로 보여준다.
- 고른 시간표에 대해 경쟁률을 바탕으로 수강신청 순서와 실패 시 대체 분반까지 정리해 준다.

## 누가 쓰나
- 성균관대 학부생. 특히 시간표를 처음 짜는 1~2학년, 전공·교양·복수전공 과목을 함께 맞춰야 하는 학생.

## 요구사항
### 핵심 (2주차 끝까지)
1. 과목 데이터 불러오기: 학수번호, 과목명, 분반, 교수, 학점, 요일·시간, 정원이 담긴 CSV를 읽는다.
2. 시간표 생성: 듣고 싶은 과목 목록을 받아 시간이 겹치지 않는 분반 조합을 모두 만든다.
3. 시간표 분석: 요일별 공강 수(0개·1개·2개 이상), 우주공강 요일, 1교시 수업 수, 총 학점을 계산한다.
4. 점수화와 정렬: 사용자가 정한 조건과 가중치로 점수를 매겨 상위 N개를 보여준다.
5. 주간 시간표 화면: 월~금 × 시간 격자로 시간표를 그린다.
6. 경쟁률 기반 신청 순서(규칙 기반): 정원 대비 희망 인원으로 경쟁률을 계산하고 신청 순서를 정한다.

### 부가 (시간이 남으면)
- LLM 수강신청 전략: 시간표, 경쟁률, 대체 분반을 LLM API에 넘겨 신청 순서의 이유, 실패 시 플랜 B, 주의할 점을 설명받는다. (3주차 목표)
- 강의평 반영: 과목별 평점과 과제 양, 학점 후함을 점수에 반영한다.
- 대체 분반 추천: 1순위 분반이 마감되면 같은 과목의 다른 분반 중 시간표를 덜 깨는 것을 제안한다.
- 시간표 이미지 저장.

### 이번에는 안 함
- 학교 시스템 자동 로그인, 자동 수강신청(매크로)
- 에브리타임 등 로그인이 필요한 사이트 크롤링
- 전 학과 전체 과목 수집 (우리 학과 전공과 교양 일부로 한정)
- 회원가입, 모바일 앱

## 전반적인 스케치
- 화면 구성 (Streamlit 웹 페이지 하나)
  - 왼쪽 사이드바: 과목 검색과 담기, 조건 설정(1교시 피하기, 우주공강 원함, 하루 공강 최대 개수, 강의평 반영 정도 슬라이더)
  - 가운데: 추천 시간표 1~N위 탭. 탭마다 주간 격자, 점수, 분석 요약(요일별 공강 수, 우주공강 요일, 1교시 수업 수)
  - 아래: [수강신청 전략 짜기] 버튼 → 신청 순서 표(과목, 경쟁률, 대체 분반)와 LLM 전략 설명
- 프로그램 흐름
  - 켜면 → 과목·경쟁률·강의평 CSV를 불러온다.
  - 과목을 담고 조건을 정한 뒤 [시간표 만들기]를 누르면 → 충돌 없는 조합을 모두 만들어 점수순 상위 N개를 보여준다.
  - 시간표를 고르고 [전략 짜기]를 누르면 → 신청 순서와 대체 분반이 나오고, LLM이 전략 설명과 플랜 B를 붙인다.
  - 끝나면 → 시간표와 전략을 이미지·텍스트로 저장한다.
- 사용할 API와 키 필요 여부
  - 과목 데이터: 성균관대 공개 과목 API를 찾지 못해, 전자시간표를 보고 30~50과목을 CSV로 직접 정리해 시작한다.
  - LLM API(OpenAI 또는 Anthropic): API 키 필요. `.env`에 저장하고 `.gitignore`에 추가한다.

## 기술적 제약조건
- Python, uv. 라이브러리: streamlit, pandas, python-dotenv, openai 또는 anthropic, pytest
- `pyproject.toml`과 `uv.lock`을 커밋해 환경을 통일한다. 실행: `uv run streamlit run app.py`

| 파일 | 하는 일 | 담당 |
| --- | --- | --- |
| `models.py` | `Course` 데이터 구조 (1주차에 함께 확정) | 공동 |
| `loader.py`, `data/*.csv` | CSV 읽기, 과목·경쟁률·강의평 데이터 정리 | 이유찬 |
| `scheduler.py` | 시간 충돌 검사, 분반 조합 생성 | 김지후 |
| `analyzer.py` | 공강·우주공강·1교시 분석, 점수 계산 | 김지후 |
| `strategy.py` | 경쟁률 계산·신청 순서 규칙(`plan`) / LLM 호출(`explain`) | 이유찬 / 김지후 |
| `app.py` | Streamlit 화면, 주간 격자 | 이유찬 |

파일끼리 주고받는 함수 약속:

```python
load_courses(path) -> list[Course]
generate(wanted: list[str], courses: list[Course]) -> list[list[Course]]
analyze(timetable) -> dict                 # 공강 수, 우주공강 요일, 1교시 수
score(analysis, weights) -> float
plan(timetable, competition) -> list[dict] # 순서, 경쟁률, 대체 분반
explain(plan) -> str                       # LLM 설명, 키 없으면 빈 문자열
```

### 구현 방법
1. **과목 데이터 (`loader.py`)**
   - 시간 문자열 `월10:30-11:45,수10:30-11:45`를 정규식으로 잘라 `(요일, 시작분, 끝분)` 목록으로 바꾼다. (10:30 → 630분)
   - 전자시간표에 로그인 없이 공개 조회되는 데이터 요청이 있으면 한 번만 받아 CSV로 저장해 쓴다. 학교 서버에 반복 요청하지 않는다.
2. **시간표 생성 (`scheduler.py`)**
   - 충돌: 요일이 같고 `a.start < b.end and b.start < a.end`이면 겹친다.
   - 백트래킹: 과목마다 분반을 하나씩 골라 넣다가 겹치면 그 가지를 바로 버린다. 분반이 적은 과목부터 고르고, 결과는 최대 5,000개에서 멈춘다.
3. **공강·우주공강·아침수업 분석 (`analyzer.py`)**
   - 요일별로 수업을 시작 시간순 정렬 → 앞 수업 끝과 다음 수업 시작 사이 간격이 60분 이상이면 공강. 요일마다 0개(연강)/1개/2개 이상으로 분류.
   - 우주공강 = `{월~금} - 수업 있는 요일`. 아침수업 = 9:00 이하에 시작하는 수업 수.
4. **강의평 반영**
   - `reviews.csv`(학수번호, 교수, 평점, 과제 양, 학점 후함)를 `(학수번호, 교수)`로 찾는다. 없는 과목은 전체 평균으로 채운다.
5. **점수와 추천**
   - 꼭 지킬 조건(1교시 금지, 학점 상한)으로 먼저 거르고, 남은 시간표는 항목을 0~1로 정규화해 가중합한다.
   - 점수 = w1·우주공강 + w2·강의평 − w3·1교시 수 − w4·공강 총시간
6. **경쟁률 기반 신청 순서 (`strategy.py`)**
   - 경쟁률 = 희망 인원 / 정원. 우선순위 = 경쟁률 × 필수 가중치 ÷ (대체 가능 분반 수 + 1). 경쟁률 1 미만은 마지막.
   - 대체 분반: 같은 과목의 다른 분반 중 나머지 과목과 겹치지 않는 것을 2개까지. 플랜 B: 1순위 과목을 놓쳤다고 보고 `generate`를 다시 돌린다.
   - 대기순번제 반영: 대기순번을 받은 과목은 다시 신청하면 순번이 초기화되므로 주의 문구를 붙인다.
7. **LLM 전략 (`strategy.py`)**
   - 6번 결과를 JSON으로 보내고 "주어진 숫자만 쓸 것"을 지시한다. 응답은 JSON으로 받아, 입력에 없는 과목이 있으면 버리고 규칙 기반 결과를 보여준다.
   - 키가 없거나 10초 안에 응답이 없으면 LLM 단계를 건너뛴다.
8. **화면 (`app.py`)**
   - `st.multiselect`·`st.checkbox`·`st.slider`로 입력, 30분 단위 × 월~금 pandas 표로 격자 표시, `st.cache_data`와 `st.session_state`로 결과 유지.
9. **테스트**: `pytest`로 충돌 검사, 공강·우주공강 계산을 작은 예제로 확인한다.

## 이러면 다 된 것
- 30과목 이상 CSV를 불러와 5과목을 담으면 충돌 없는 시간표가 모두 생성되고 상위 5개가 화면에 나온다.
- "1교시 피하기"를 켜면 9시 수업이 있는 시간표가 상위권에서 빠진다.
- 각 시간표에 요일별 공강 수, 우주공강 요일, 1교시 수업 수, 총 학점이 표시된다.
- [전략 짜기]를 누르면 신청 순서와 과목별 대체 분반이 표로 나온다.
- LLM 키가 있으면 전략 설명이 붙고, 키가 없어도 멈추지 않고 규칙 기반 결과를 보여준다.
- 처음 받은 사람이 README대로 `uv sync` 후 `uv run streamlit run app.py`로 실행할 수 있다.

## 그 외 코멘트
- 과목 데이터: 학교 공개 과목 API를 찾지 못해 전자시간표를 보고 직접 정리한다. 학교 데이터를 과제에 써도 되는 범위가 궁금하다.
- 강의평: 에브리타임은 로그인이 필요하고 약관 문제가 있어 크롤링하지 않는다. 직접 입력한 소규모 데이터로 대신한다.
- 경쟁률: 희망 인원 데이터가 공개되는지 확실하지 않다. 없으면 사용자가 예상치를 입력한다.
- 매크로: 학교 안내문에 수강신청 매크로·다중접속이 제한된다고 되어 있어 자동 신청 기능은 만들지 않는다.
- 조합 폭발: 과목·분반이 많으면 조합이 수천 개가 될 수 있어, 충돌 즉시 가지치기하고 상위 N개만 유지한다.
- LLM: 숫자를 지어낼 수 있으므로 계산은 코드가 하고 LLM은 설명만 한다.
- 강의자에게 묻고 싶은 것: LLM API 비용 지원이 있는지, 학교 공개 데이터를 어디까지 써도 되는지.
